What's inside

Alias-free wavetable engine

Mipmapped, band-limited oscillators. Measured aliasing below −116 dB at every pitch — clean where cheap synths get harsh.

808s that knock

Dedicated pitch envelope, mono glide for real 808 slides, and a 4×-oversampled drive stage for saturation without digital grit.

Moog-style ladder filter

24 dB/oct analog-modeled lowpass with musical resonance, its own ADSR, and key-ready envelope amounts.

16-voice stereo unison

Detuned saw stacks spread across the field — supersaws, reeses, and anthem leads out of the box.

Deep modulation

Two LFOs (pitch / filter / amp) plus a 4-slot mod matrix: route velocity, envelopes, or LFOs anywhere.

Import your own wavetables

Load any single-cycle WAV into OSC 1 — it's automatically band-limited so it stays clean at every note.

61 presets, hip-hop first

Trap 808, Drill Flute, Plugg Keys, G-Funk Whistle, Boom Bap Keys, wobbles, pads, bells — organized by category.

Plays like an instrument

Velocity-sensitive, MIDI Learn on every knob, full host automation with readable values, presets savable from the GUI.

Install

macOS
  1. Download and open the .pkg. It installs the VST3, AU, and standalone app.
  2. Beta builds are unsigned: if macOS blocks it, right-click the .pkg → Open, or allow it under System Settings → Privacy & Security.
  3. Rescan plugins in your DAW — Ember-8 appears under Generators / Instruments.
Windows
  1. Unzip, then copy the Ember-8.vst3 folder to C:\Program Files\Common Files\VST3.
  2. If SmartScreen appears on the standalone app: More info → Run anyway (beta builds are unsigned).
  3. Rescan plugins in FL Studio (Options → Manage plugins → Find plugins).
Beta. Ember-8 is in open beta — it's free, and feedback shapes v1.1. Found a bug or want a sound added? Open an issue.
